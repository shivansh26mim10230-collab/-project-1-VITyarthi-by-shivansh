# This program works as a password suggestion and strength checker A
1. This program works on generating a random strong password 
2. Lets you type your own password and will check the strength of the given password 



# To run this program you need :- 
python 3 
## How to run 
1. open the file named project1.py in the terminal 
2. then enter your passwords while considering the above suggested passwords and taking them as reference
3. now the test results are in front of you marking the strength of your password 



## How it works :-

1) generate_password_suggestions() builds random passwords by picking characters one at a time from a pool of letters, digits, and symbols.

2) check_password_strength() scans your password character by character, checks which categories it uses (lowercase, uppercase, digits, symbols), and its length, then adds up a score and gives feedback.
